# 📖 雅思阅读器 · 每日阅读 + 背单词

一个纯静态的英语学习小网站（为 IELTS 6.5 备考，适合 CET-4 / 雅思 5–5.5 水平的中文学习者）。
不需要后端、不需要构建，直接放到 GitHub Pages 即可使用；所有学习数据保存在浏览器 localStorage。

## 功能

| 页面 | 说明 |
|---|---|
| 📰 **今日阅读** | 打开即显示最新一篇文章（`articles/index.json` 第一项），带中文导读、重点词汇、原报道链接；下方是往期文章列表（`#/read/YYYY-MM-DD`）。 |
| 🔁 **复习** | 词义题先写意思，再对照释义自评；穿插隐藏目标词的语境填空，综合模式加练拼写。每词每天一次正式测试，各能力分天安排。全部词测完后可选一次错词补练，至少隔开 8 个不同词，间隔不足留到明天。新词当天答对、提示和补练不计独立掌握。支持草稿续练、认识词 7 天后抽查和延迟保持统计。 |
| 📒 **生词本** | 搜索、排序、按类型 / 来源筛选（单词、短语、阅读收藏、手动添加、四六级）、遮住中文、显示复习阶段和下次复习日期；**✍️ 手动添加**单词 / 短语 / 短句（中文可自己填，也可一键自动翻译，可加备注 / 例句）；每条都能点 ✏️ **修改中文意思**；导出 CSV（含类型、备注列）；**导出 / 导入 JSON 备份**（合并或覆盖），用于手机 ⇄ 电脑迁移。 |
| ✏️ **自己粘贴** | 粘贴任意英文文章进入阅读模式（保留原来的功能和两篇示例）。 |

**整段译文**：文章带有 `paragraphs_zh` 时，每段末尾有一个「整段对照」按钮，点一下在该段下方显示 / 隐藏中文译文；文章顶部的「全文对照」一次显示 / 隐藏全部译文，并记住你的选择（下次打开文章默认同样显示或隐藏）。译文是逐段人工智能精译后写进文章 JSON 的，不依赖在线翻译接口，国内也能直接显示。

**逐句翻译讲解**：每个英文句子末尾都有「翻译·讲解」，点击后由 DeepSeek 按“参考译文 → 句子主干 → 翻译顺序 → 实用短语 → 迁移提示”讲解。无需先输入自己的译文，AI 接收指定原句和所在段落作为上下文，讲解只针对这一句。使用原有 `deepseek-chat` 流式接口和本机密钥。打开文章不调用 AI，已保存的讲解重复查看不再调用；「重新生成」会再次请求。生成中可停止，离开文章会取消进行中的请求；失败保留上次讲解，被截断的回复会标注。讲解可点「加入明天复译」用于次日练习。旧版整段草稿和批改保留在每段下方的“查看此前的整段翻译记录”中。

在设置 →「DeepSeek 逐句翻译讲解」填写自己的 API 密钥。**密钥仅保存在当前浏览器的 `er_ds_key`，不进备份和 GitHub 同步**。讲解作为 `er_learning` 中的 `lesson:` 记录保存，包含原句、上下文、参考译文、讲解和更新时间；上下文变化时不会误用旧讲解。离线可看已保存的结果，生成新讲解需要网络和有效密钥。

所有阅读模式中：电脑**双击**、手机**轻点**单词 → 弹出音标、中文释义、英文释义、例句、发音，可一键加入生词本（加入后当天就会出现在复习里）。

### 短语 / 短句

- **电脑**：在文章里按住鼠标**拖选**两个以上的词，松开后选区下方弹出小窗口（选区会自动扩展到完整单词）。
- **手机**：用系统自带的**长按选词**，再拖动两端的选择柄调整范围；手指离开、选区停止变化约半秒后，底部弹出面板（不会挡住系统的复制 / 查询菜单；如果选区靠近屏幕底部，页面会自动上移，让选区留在面板上方）。长按只选中一个词时，和轻点一样弹出单词释义。
- 弹窗里有：选中的短语（≤ 20 个词，超过会提示「太长」）、中文意思（先查本文短语表 / 重点词，再依次在线翻译：有道 → MyMemory → Google，每个最多等 5 秒；可直接修改；都失败时显示逐词意思作参考，可「重试翻译」）、🔊 朗读（浏览器语音合成，遵循设置里的美音 / 英音）、「加入生词本」。原句会一起保存。
- 已收藏的短语在文中用**绿色下划线**标出。
- 复习：短语同样先主动回忆词义；有可用原句时练语境填空。「综合」模式加入拼写 / 听写，比较短语时忽略大小写、标点和多余空格，错误会逐词标注。超过 6 个词的短语先用连词成句辅助，选项辅助不会晋级，后续独立听写才作为无提示证据。

查词来源：Free Dictionary API（dictionaryapi.dev）→ 英文维基词典兜底；中文释义依次来自内置四六级词库、中文维基词典、MyMemory 翻译、英文维基词典译词。短语 / 短句的中文：本文短语表 / 重点词 → 有道机器翻译（aidemo.youdao.com，国内可直连）→ MyMemory → Google（translate.googleapis.com，国内通常连不上），都是免 key、支持 CORS 的接口，结果缓存在本地。发音优先用词典音频，其次浏览器语音合成。

## 阅读、听写和翻译错题

- **阅读理解**：现有 11 篇文章各有 3 道题（主旨、细节、推断）。读完选择答案，提交后看解析、原文引文并定位到正文段落。刷新保留结果；重做同时保留首次成绩，避免把看过答案的练习当成首次理解。
- **翻译复练**：逐句讲解完成后点「加入明天复译」，次日先写中文，再对照参考译文。旧的错题继续保留，也能从历史整段批改中导入或手动补充。复练不额外调用 AI，提示后完成不会按独立回忆晋级。
- **逐句听读 / 听写**：文章顶部可选择句子、0.6 / 0.8 / 1 / 1.2 倍速和 1–3 次重复，重复间留 2 秒跟读。听写模式收起正文与当前原句；提交后按词标出漏写、多写和写错，忽略大小写与标点。看原句提示会记录为辅助练习。离开页面、切换句子或关闭面板会停止播放。采用设备语音合成，不录音、不识别或评估口音；无语音支持时显示明确提示。
- **文章推荐**：往期列表上方显示 3 篇推荐，可选接近当前难度、轻松巩固、挑战。比较已知不熟词的出现负担、平均句长和词数，参考复习状态、最近 14 天查词记录和你明确标记的词汇熟悉度。尚未观察的词保留「未判断」，不会当作生词；数据不足时说明暂按篇幅和句长推荐。可用 8 个词快速校准，也可标记本文读起来偏轻松 / 刚刚好 / 偏吃力。

新记录保存在 `er_learning`，包含逐题作答、翻译错题、听写结果、词汇熟悉度、查词记录和阅读难度反馈；备份和 gist 同步都包含这些记录，按每项 `updatedAt` 合并。正在播放的音频、未提交听写草稿和错题答案的临时显示状态不会跨设备同步。词语匹配率、文章推荐和错题自评都不代表雅思等级。

后续文章可继续添加 `questions` 字段。题目使用英文题干和选项、中文解释；`answer` 和 `evidence.paragraph` 从 0 开始，`quote` 必须逐字出现在引用段落内。`scripts/add_article.py` 会检查答案索引、题目 ID 和引文。缺少题目的文章仍可听读、翻译和查词，理解区会明确显示尚未配题。

```json
"questions": [{
  "id": "q1", "type": "detail",
  "prompt": "What does the passage say about the ocean?",
  "options": ["It absorbs heat.", "It produces no change."],
  "answer": 0,
  "explanation": "原文明确说明海洋吸收热量。",
  "evidence": [{"paragraph": 0, "quote": "It absorbs heat."}]
}]
```

## 每日复习的记忆规则

- **写答案再揭晓**：词义题先写一个核心意思或自己的解释；不能空白提交或照抄英文。「想不起来」直接记为忘记并展示释义。「原句提示」记为有提示。揭晓后锁定原答案，与释义并排核对；中文同义表达由用户自评，不做字面匹配自动判分。原答案随学习历史保存和备份。
- **三条能力独立、分天练习**：`meaning`（词义）、`usage`（语境）、`spelling`（拼写）。每词每天只安排一项正式测试，优先近期未测的到期能力；有可用例句的旧词会穿插语境题，新词次日优先验证词义。其余到期能力只延期到次日，不编造答题或晋级记录。阅读模式不安排拼写积压，综合模式加入拼写。语境题默认显示目标中文意思和例句中文，要求写出英文；这些中文是正常题干。只有额外请求英文首字母提示才计辅助，不晋级。短语只挖完整短语，不再退化成任意单词。语境通过记录在 usage，不冒充无中文提示的词义回忆。
- **先测完，再选补练**：正式队列不插入重试。全部不同词完成后，与上次出现间隔至少 8 个不同词的错词，可以选择补练一次，也可以结束。只有三四个词或间隔不足时直接结束。新词当天仅做一次初练，次日再验证。补练再错也不追加题目；`learningPending` 只在后续正式无提示答对后清除，当天练习不能覆盖首次错误。
- **控制负担**：每轮最多 30 个到期词，已学到期词优先，再学阅读 / 手动收藏，最后补充四六级。到期词达到 15 个时最多补充 2 个新词，达到 30 个暂停补充。默认每天 5 个新词，已有用户设置保留。
- **认识也抽查**：「已认识」保留词条，7 天后测试。旧版永久跳过的词可在首页点击恢复低频抽查。
- **进度与统计**：同日可暂停、刷新继续，包括词义答案草稿、揭晓状态和可选补练阶段；进度按不同单词计数。升级时废弃旧的重复队列，保留已有生词和评分记录。队列只保存在本机，不参与跨设备同步。首页展示昨日新词今日回忆情况和最近 7 天中间隔至少 7 天的抽查，每词只计最近一次。包括词义自评，提示成功和当天重练不计独立通过。旧记录不足时显示待验证。
- **更谨慎的掌握标准**：词义至少 3 个不同日期无提示通过，并有一次间隔至少 7 天的成功回忆，且当前没有未完成的加强任务，才显示已通过延迟验证。旧版高阶段不会直接算作已验证。

## 键盘操作

| 场景 | 按键 | 操作 |
| --- | --- | --- |
| 复习 | Enter | 开始、提交答案、下一词；揭晓后不会自动给“准确”评分 |
| 词义核对 | 1 / 2 / 3 | 意思不对 / 部分正确 / 意思准确 |
| 复习 | Alt + H / P / N | 额外提示 / 发音 / 想不起来 |
| 复习 | Esc | 暂停当前轮次 |
| 多行输入 | Shift + Enter | 换行 |
| 阅读 | Alt + ↑ / ↓ | 聚焦上一句 / 下一句的翻译入口 |
| 阅读 | Alt + T | 展开或收起当前句讲解 |

数字、字母在输入框内照常输入；中文输入法正在选字时不会误提交。设置窗口和查词弹窗打开时不会触发复习快捷键。

复习例句优先使用已保存中文、文章标题中文或已保存的逐句讲解译文；缺失的句子中文通过现有翻译服务获取并缓存。网络失败时，有匹配文章的词会显示明确标注的“所在段落中文（语境参考）”，不会冒充逐句译文；仍可重试。普通词义题的中文在提交后显示，中译英填空在作答前显示中文。

## 本地运行

浏览器不允许 `file://` 页面读取 JSON，所以请用本地服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

部署：把仓库推到 GitHub，Settings → Pages → Deploy from branch → `main` / root。所有路径都是相对路径。

## 每日文章 JSON 格式

`articles/YYYY-MM-DD.json`：

```json
{
  "date": "2026-10-23",                 // YYYY-MM-DD，也是文件名
  "title": "English title",
  "title_zh": "中文标题",
  "source_name": "媒体名称 / 原文标题",
  "source_url": "https://…",            // 原始报道链接
  "level": "B1–B2 · 雅思 5.5–6.5",
  "summary_zh": "中文导读",
  "paragraphs": ["段落 1", "段落 2"],     // 非空字符串数组
  "paragraphs_zh": ["第 1 段的中文译文", "第 2 段的中文译文"],  // 可选：逐段中文译文，与 paragraphs 一一对应
  "key_words": [                         // 可为空数组
    {"word": "emission", "phonetic": "/iˈmɪʃn/", "meaning_zh": "n. 排放；排放物"}
  ],
  "phrases": [                           // 可选：15–25 个文中出现的常用短语 / 搭配
    {"text": "failed harvests", "meaning_zh": "歉收；收成不好"}
  ]
}
```

所有字符串字段必填且非空（`key_words[].phonetic` 可以是空字符串）。`phrases` 可省略；如果有，每项的 `text`（原文里的英文短语）和 `meaning_zh`（含中文）都必须非空，不能重复。读者拖选短语时会先查本文的 `phrases` 和 `key_words`（忽略大小写和标点，包含 / 被包含也会提示），查不到才在线翻译。

`paragraphs_zh` 可省略（校验时会给出 warning）；如果有，必须是与 `paragraphs` **长度相同**的非空字符串数组，每项含中文，是对应英文段落的完整、准确、通顺的译文（注意代词指代、省略的主语、「one in three」「twice as likely as」这类比例表达和中文语序）。有译文时，阅读页每段末尾出现「整段对照」按钮（显示 / 隐藏本段译文），文章顶部有「全文对照」开关（一次显示 / 隐藏全部译文，选择记在 localStorage 的 `er_para_zh`）；没有 `paragraphs_zh` 的文章不显示这些按钮。译文不参与查词：双击 / 拖选只对英文生效。

`articles/index.json`：`[{"date": "2026-10-23", "title": "…", "file": "2026-10-23.json"}, …]`，按日期**从新到旧**排列，日期不重复。

### 添加文章

```bash
python3 scripts/add_article.py path/to/my-article.json   # 校验 → 复制为 articles/<date>.json → 更新 index.json（同日期覆盖，新→旧排序）
python3 scripts/add_article.py --validate-only file.json # 只校验
python3 scripts/add_article.py --check                   # 校验 index.json 中的全部文章
```

只用 Python 标准库。文章应为根据新闻**原创改写**的学习材料，`source_url` 指向真实报道。

## 数据与备份

localStorage 键：`er_vocab`（生词 / 短语，每条有 `word`、`type`（`"word"` 或 `"phrase"`）、`zh`、`sentence`、可选 `note`、`source`（`reading` / `manual` / `cet4` / `cet6`）以及 `srs` 进度：兼容字段 `stage`、`due`、`reps`、`lapses`、`last`、`qn`，以及 `skills.meaning/usage/spelling` 独立进度和最近最多 200 条 `history` 事件）、`er_cet_seen`（已学/已标记认识的四六级词）、`er_review_session`（当天队列、提示与回忆状态，仅本机）、`er_daily`（今日已展示的补充新词数）、`er_settings`、`er_cache`（查词缓存）、`er_para_zh`（「全文对照」开关，true / false，仅本机）、`er_tr`（旧版整段翻译历史：键为 `YYYY-MM-DD#段落序号`，值 `{text, fb, fbFor, fbAt, truncated, updatedAt}`，即草稿、最近一次批改、批改对应的译文、批改时间；会同步）、`er_ds_key`（DeepSeek API 密钥，**仅本机**，从不同步 / 备份）。
GitHub gist 同步的 JSON 在有练习记录时多一个 `translations` 字段（内容同 `er_tr`），按每段的 `updatedAt` 取较新的一份合并；没有练习记录时格式与以前完全相同，旧数据照常可用。
「导出备份」生成 `{"app":"english-reader","version":2,"data":{vocab, cetSeen, daily, settings, translations, learning}}`（不含 DeepSeek 密钥；导入时 `translations` 总是按段合并）。
「导入（合并）」：两边都有的词保留最近复习过的那份进度；「导入（覆盖本地）」：完全用备份替换。

旧版生词本（同一个 `er_vocab` 键）自动迁移：已有阶段和复习日期映射为词义进度；没有进度的词才从阶段 0 开始，历史释义、例句、笔记和自定义字段保留。备份及 gist 同步包含分能力进度和历史记录；同步仍按整条词的最新记录合并，多设备同时离线练习同一个词时不会逐事件合并。
没有 `type` 字段的旧数据 / 旧备份照常可用：含空格的条目自动当作短语，其余当作单词。合并导入时按「忽略大小写和标点」判断是否同一条。

## 已知限制

- 查词依赖第三方免费接口（dictionaryapi.dev、Wiktionary、MyMemory），偶尔会不可用或限额；会自动降级，四六级词库内的词离线也有中文释义。
- 发音依赖设备的语音合成；部分安卓浏览器没有英文语音时改用有道词典发音链接。
- 短语翻译是机器翻译（有道 / MyMemory / Google），固定搭配 / 习语可能译得生硬，建议加入前顺手改一下；匿名额度每天约 5000 字符，设置里填邮箱可提高。
- 手机上的短语面板依赖浏览器的原生选区事件（`selectionchange`），在 iOS Safari / 安卓 Chrome 上可用；个别国产浏览器或微信内置浏览器会拦截长按选词，这时可用「生词本 → 手动添加」。
- 短语高亮只匹配同一段落内连续出现的原词（不做词形还原，例如收藏 *make ends meet* 不会高亮 *made ends meet*）。
- 逐句 AI 讲解可能不准确，结合原文核对；新讲解和重新生成使用你自己的 DeepSeek 额度，重复打开缓存不请求。测试使用模拟服务，不代表真实 AI 输出质量或账户可用性。
- 旧版本页面（缓存未刷新的标签页）同步时不认识 `translations` 字段，可能把它覆盖掉；更新后请刷新其他设备上已打开的页面。
- 数据只在当前浏览器；清除浏览器数据会丢失，请定期导出备份。
- 每日文章需要手动（或由助手）用 `add_article.py` 添加，网站本身不会自动抓取新闻。
