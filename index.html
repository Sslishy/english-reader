    💾 备份 / 迁移（手机 ⇄ 电脑）

    所有数据只保存在本浏览器（localStorage）。换设备前先「导出备份」，在另一台设备上「导入」即可。备份包含生词本、复习进度、已学四六级词和设置。

    手机上不方便下载文件时，用「备份码」：复制后粘贴到备忘录或微信「文件传输助手」保存；在另一台设备上粘贴导入即可。本机还会自动保留最近一次的生词本副本，生词本被意外清空时可在上方一键恢复（清除浏览器数据时副本也会被清掉）。

    ☁️ GitHub 同步（电脑 ⇄ 手机自动同步）

    把生词本、短语、复习进度、每日新词进度和设置自动保存到你自己 GitHub 账号里的一个私密（secret）gist，多台设备填同一个 token 就会自动合并同步。

    1. 登录 GitHub 后打开 生成 token 页面（已自动勾选 gist，其他权限都不要勾）。
    2. 「Expiration」可选 90 天或 No expiration，拉到底点「Generate token」。
    3. 复制以 ghp_ 开头的 token，粘贴到下面，点「连接并同步」。另一台设备重复第 3 步（可用同一个 token）。

    也可以用 fine-grained token：权限里只给 Gists：Read and write。

    🔒 token 只保存在这台设备的浏览器里，不会上传到别处；它只有 gist 权限，不能动你的代码仓库。secret gist 不会公开列出，但知道链接的人可以看到内容，请不要把 gist 链接或 token 发给别人。不用时可在 GitHub 的 token 设置里随时删除它。
